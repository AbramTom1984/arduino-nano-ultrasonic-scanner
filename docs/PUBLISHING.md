## Upload the folder contents

1. Extract the ZIP archive.
2. Create a new repository on GitHub using the suggested name or your own.
3. Leave automatic README, license, and .gitignore initialization disabled: these files are already included.
4. Upload the contents of the extracted project folder, preserving the directory structure.
5. Ensure `README.md` and `LICENSE` are at the repository root, not inside an extra nested project folder.
6. Commit the files and review the rendered README and photographs.

Some file pickers hide `.gitignore` and `.gitattributes`. Include them too, or use Git to add the complete folder.

No GitHub account name, remote URL, or online publication is assumed by this package.

## Optional Git workflow

Run inside the extracted project directory after creating an empty remote repository:

```bash
git init
git add .
git commit -m "Initial release: ultrasonic scanner with photos and documentation"
git branch -M main
```

Then add the exact remote URL provided by GitHub with `git remote add origin`, and push using `git push -u origin main`. Authentication depends on your GitHub setup.
