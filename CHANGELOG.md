# Changelog

## 1.0.0 - 2026-10-27

- Packaged the Arduino Nano ultrasonic scanner and Processing visualization.
- Included all seven supplied project photographs and a composite project cover.

- Added MIT licensing and copyright attribution to Tomasz Abramowicz.
- Preserved the prototype's 30–150° scan, 3° step, 100 cm display, and 50 cm threshold.
